# Pokémon-checklista

Mobilanpassad PWA för Pokémon-checklistan. Avbockningar sparas lokalt på enheten med `localStorage`.

## Källa
Innehållet följer den Fandom-lista som användaren angav: https://pokemon.fandom.com/wiki/List_of_Pok%C3%A9mon_by_three-stage_evolution

## Bilder
Pokémon-bilderna laddas från PokéAPI:s sprites-repository.

## Installera på iPhone
Öppna den publicerade HTTPS-sidan i Safari och välj **Dela → Lägg till på hemskärmen → Öppna som webbapp → Lägg till**.

## GitHub Pages
Aktivera Pages i repositoryts **Settings → Pages** och välj **Deploy from a branch**, branch `main`, folder `/ (root)`. Därefter kan sidan öppnas via den GitHub Pages-adress GitHub visar.
